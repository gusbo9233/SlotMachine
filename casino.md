# Casino Slots Game

# Project Specification


## Test assignment

Create a simple slot game. Feel free to create it “in your own style”, if you need
inspiration, please see picture below.
The slot game should be browser based and responsive for different mobile screens
(phone and tablet). How you write it and if you choose to go with ether pure
JavaScript or use React is entirely up to you, but in the end you should deliver a
solution that's HTML5 based, eg: HTML, CSS and JavaScript, plus the source-
code.
The end goal here is not that we want you to revolutionize the world of slots.
However, we want to see how you approach coding, how you structure code, how
you prioritize, why you chose one solution instead of another, what you would have
done if you had more time etc.


## Game instructions

1. Player press Spin button
2. Reels start to spin and stop at random position.
3. If win line has at least 2 same symbols at the same central horizontal position
    software indicates player
    that he has won

## Mandatory features

### REELS

### RESULTS INSPECTION
